Платформы / Windows

KalderaShield на Windows

Поддерживаются Windows 10 и 11 на x64 в трёх форматах установки: стандартный мастер установки NSIS, пакет MSI для управляемого развёртывания и переносимый исполняемый файл, работающий без установки.

Что вы получаете

Три способа установки

Мастер setup.exe устанавливает для пользователя или для всей машины, добавляет ярлыки в меню «Пуск» и собственный деинсталлятор. Пакет MSI существует для сред, где развёртывание ПО ожидает именно этот формат. Переносимому исполняемому файлу ничего этого не нужно: распакуйте и запустите.

Все три варианта собирают одно и то же приложение. Файл хранилища, зашифрованные резервные копии и настройки переносимы между ними, а контрольные суммы SHA-256 публикуются для каждого артефакта, чтобы вы могли проверить именно тот файл, который устанавливаете.

Активны специфичные для Windows защиты: окна запрашиваются с WDA_EXCLUDEFROMCAPTURE, что убирает приложение из обычных скриншотов, записи экрана и предпросмотра переключателя задач, а Windows Hello упаковывает блок данных разблокировки для удобства с помощью платформенного аутентификатора на базе TPM 2.0.

Начало работы на Windows

Скачайте и проверьте

Загрузите установщик со страницы загрузки, затем сверьте его хэш SHA-256 с соответствующей строкой в SHA256SUMS.txt перед запуском.

Создайте хранилище

Выберите мастер-пароль — Argon2id с 64 MiB, 4 итерациями и 2 потоками растягивает его в ключ хранилища — и сохраните ключ восстановления из 24 слов BIP-39 вне приложения.

При желании добавьте Windows Hello

Зарегистрируйте платформенную разблокировку, чтобы ежедневный доступ был взглядом или PIN-кодом, с поддержкой TPM 2.0. Мастер-пароль всегда остаётся подлинной основой хранилища.

Архитектура безопасности

Особенности Windows, которые стоит знать

Подписи и SmartScreen

Установщики Windows пока не несут подписи Authenticode: у проекта нет сертификата подписи кода, а релизный шлюз блокирует публикацию неподписанных артефактов как официальных релизов. Пока это не изменилось, Windows SmartScreen может показывать «Windows защитила ваш компьютер» для файлов, полученных из сборки, — сверьте хэш SHA-256 с опубликованными контрольными суммами и посмотрите страницу проверки, чтобы понять, что означает это предупреждение, а что нет.

Разблокировка Windows Hello

Платформенный аутентификатор WebAuthn PRF упаковывает блок данных разблокировки; материал ключа упаковки никогда не покидает защищённое аппаратное обеспечение.

WDA_EXCLUDEFROMCAPTURE

Исключение из захвата экрана

Окна приложения исключены из обычного захвата экрана. Привилегированное ПО захвата вне модели угроз, как и везде.

Часто задаваемые вопросы

Вопросы о Windows

Setup.exe, MSI или переносимая версия — что выбрать?

Для личного компьютера — мастер установки. Для управляемого развёртывания — MSI. Для USB-накопителя или машины, где вы предпочитаете обойтись без установки, — переносимый исполняемый файл.

Почему SmartScreen предупреждает об установщике?

Потому что он не подписан и не имеет репутации загрузок. Сверьте хэш SHA-256 с SHA256SUMS.txt; страница проверки объясняет картину целиком, включая то, почему предупреждение исчезнет после появления сертификата подписи.

Можно ли перенести хранилище на другой ПК с Windows?

Да. Экспортируйте зашифрованную резервную копию .ks, перенесите её и восстановите с мастер-паролем. Файл хранилища переносим и не привязан к одной машине или одному формату установки.
