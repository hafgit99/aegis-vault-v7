Быстрая установка через CLI (Одна команда)

Скачайте и установите последнюю версию одной командой в терминале:

Скрипт во время работы получает номер версии и контрольные суммы SHA-256 из GitHub Releases, сверяет их с SHA256SUMS.txt и останавливает установку, если что-то не совпало.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
Ещё не опубликовано

Пакеты для Windows и macOS пока не выпускаются по причинам, указанным ниже.

Windows

Windows 10 64-бит и новее

Оптимизированный нативный установщик MSI на базе Tauri или портативная версия EXE.

Скоро в Microsoft Store

Store переподписывает пакет собственным сертификатом: установка без предупреждений SmartScreen, и никому не нужно покупать сертификат подписи кода.

macOS

Ожидается официально подписанная версия

Процесс сертификации подписи кода (Code Signing) и нотаризации Apple Gatekeeper находится в процессе. Установочные пакеты для macOS временно приостановлены.

Следить за обновлениями на GitHub

Для Android

Установка в 4 шага

  1. 1

    Скачайте APK-файл

    Выберите подходящий пакет: для большинства смартфонов подходит универсальный или ARM64 APK.

  2. 2

    Проверьте хэш и подпись

    SHA-256 проверяет целостность файла; подпись Sigstore подтверждает рабочий процесс сборки.

  3. 3

    Разрешайте установку из неизвестных источников только во время установки

    После успешной проверки предоставьте разрешение исключительно для скачанного APK-файла.

  4. 4

    Создайте или восстановите хранилище

    Установите проверенный APK и создайте или восстановите хранилище.

Проверка

Проверка целостности загрузок

Каждый релиз поставляется с SHA256SUMS.txt и подписями PGP/.sig. Сверьте контрольные суммы перед установкой.

Примечание: Загрузки публикуются в GitHub Releases.

Контрольные суммы SHA-256 всех установочных файлов: Инструкция по проверке 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
