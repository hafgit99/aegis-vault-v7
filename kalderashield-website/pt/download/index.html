Instalação Rápida CLI (Comando Único)

Baixe e instale a versão mais recente em uma linha de comando:

O script busca o número da versão e as somas SHA-256 no GitHub Releases enquanto é executado, compara com SHA256SUMS.txt e interrompe a instalação se algo não corresponder.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
Ainda não publicado

Os pacotes de Windows e macOS ainda não são publicados, pelos motivos indicados abaixo.

Windows

Windows 10 64 bits ou superior

Instalador MSI nativo otimizado baseado em Tauri ou executável portátil.

Em breve no Microsoft Store

A Store reassina o pacote com o próprio certificado: você instala sem avisos do SmartScreen e sem precisar comprar um certificado de assinatura de código.

macOS

Aguardando versão assinada oficial

O processo de assinatura de código (Code Signing) e notarização do Apple Gatekeeper está em andamento. Os instaladores para macOS estão temporariamente suspensos.

Acompanhar lançamentos no GitHub

Para Android

Instalação em 4 passos

  1. 1

    Baixe o arquivo APK

    Escolha o pacote certo para seu dispositivo: APK Universal ou ARM64 para a maioria dos smartphones.

  2. 2

    Verifique o hash e a assinatura

    O SHA-256 verifica a integridade do arquivo; a assinatura Sigstore valida o fluxo de lançamento.

  3. 3

    Conceda permissão de fontes desconhecidas apenas durante a instalação

    Após a verificação ser bem-sucedida, conceda a permissão exclusivamente para o APK baixado.

  4. 4

    Crie ou restaure seu cofre

    Instale o APK verificado e crie ou restaure seu cofre.

Verificação

Verifique seus downloads

Cada versão é distribuída com SHA256SUMS.txt e assinaturas PGP/.sig. Compare os hashes antes de instalar.

Nota: Os downloads são servidos pelo GitHub Releases.

Digests SHA-256 de todos os instaladores: Ver guia de verificação 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
