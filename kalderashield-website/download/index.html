CLI Hızlı Kurulum (Tek Komut)

Terminal üzerinden tek satırda en güncel sürümü indirin ve kurun:

Betik, sürüm numarasını ve SHA-256 özetlerini çalışma anında GitHub Releases üzerinden çeker; özetler SHA256SUMS.txt ile karşılaştırılır ve eşleşmezse kurulum durdurulur.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
Henüz yayımlanmadı

Windows ve macOS paketleri aşağıda belirtilen nedenlerle henüz yayımlanmıyor.

Windows

Windows 10 64-bit ve üzeri

Tauri tabanlı optimize edilmiş native Windows MSI yükleyici veya taşınabilir (portable) EXE.

Microsoft Store'a geliyor

Store, paketi kendi sertifikasıyla yeniden imzalar. Böylece SmartScreen uyarısı olmadan, hiçbir kod imzalama sertifikası satın almadan kurarsınız.

macOS

Resmi İmzalı Sürüm Bekleniyor

Apple Gatekeeper ve kod imzalama (Code Signing) sertifikasyon süreci devam etmektedir. İmzalı resmi sürüm hazır olana kadar macOS kurulum paketleri geçici olarak sunulmamaktadır.

Android İçin

4 Adımda Kurulum

  1. 1

    APK dosyasını indirin

    Cihazınız için doğru paketi seçin: çoğu telefon için Evrensel veya ARM64 APK.

  2. 2

    Özet ve imzayı doğrulayın

    SHA-256 dosya bütünlüğünü denetler; Sigstore imzası yayın iş akışını doğrular.

  3. 3

    Bilinmeyen kaynak iznini yalnızca kurulumda verin

    Doğrulama başarılı olduktan sonra bu izni yalnızca indirdiğiniz APK için verin.

  4. 4

    Kasanızı oluşturun veya geri yükleyin

    Doğrulanmış APK’yı yükleyin ve kasanızı oluşturun veya geri yükleyin.

Doğrulama

İndirmeleri Doğrulayın

Her sürüm SHA256SUMS.txt + PGP/.sig imzalarıyla yayınlanır. Kurulumdan önce özetleri karşılaştırın.

Not: İndirmeler GitHub Releases üzerinden sunulur.

Tüm kurulum dosyalarının SHA-256 özetleri: Doğrulama Rehberini İnceleyin 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
