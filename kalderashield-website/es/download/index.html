Instalación Rápida CLI (Comando Único)

Descargue e instale la última versión en una sola línea:

El script obtiene el número de versión y las huellas SHA-256 desde GitHub Releases mientras se ejecuta, las compara con SHA256SUMS.txt y detiene la instalación si algo no coincide.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
Todavía no publicado

Los paquetes de Windows y macOS aún no se publican, por las razones indicadas abajo.

Windows

Windows 10 de 64 bits y posterior

Instalador MSI optimizado basado en Tauri o ejecutable portable independiente.

Próximamente en Microsoft Store

La Store vuelve a firmar el paquete con su propio certificado: instalarás sin advertencias de SmartScreen y sin necesidad de comprar un certificado de firma de código.

macOS

En espera de versión firmada oficial

El proceso de certificación de firma de código (Code Signing) y notarización de Apple Gatekeeper está en curso. Los instaladores para macOS están temporalmente suspendidos.

Seguir lanzamientos en GitHub

Para Android

Instalación en 4 pasos

  1. 1

    Descarga el archivo APK

    Elige el paquete adecuado para tu dispositivo: APK Universal o ARM64 para la mayoría de teléfonos.

  2. 2

    Verifica el resumen y la firma

    SHA-256 valida la integridad del archivo; la firma Sigstore autentica el flujo de publicación.

  3. 3

    Concede permiso de fuentes desconocidas solo durante la instalación

    Tras una verificación exitosa, concede este permiso exclusivamente para el APK descargado.

  4. 4

    Crea o restaura tu caja fuerte

    Instala el APK verificado y crea o restaura tu caja fuerte.

Verificación

Verifica tus descargas

Cada versión se distribuye con SHA256SUMS.txt y firmas PGP/.sig. Compara los resúmenes antes de instalar.

Nota: Las descargas se sirven desde GitHub Releases.

Resúmenes SHA-256 de todos los instaladores: Ver guía de verificación 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
