CLI Quick Install (Single Command)

Download and install the latest release in one terminal line:

The script fetches the version number and the SHA-256 digests from GitHub Releases while it runs, compares them against SHA256SUMS.txt, and stops the installation if anything does not match.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh

For Android

Installation in 4 Steps

  1. 1

    Download the APK file

    Pick the right package for your device: Universal or ARM64 APK for most phones.

  2. 2

    Verify digest and signature

    SHA-256 verifies file integrity; Sigstore signature verifies the release workflow.

  3. 3

    Grant unknown sources permission only during install

    After verification succeeds, grant this permission solely for the downloaded APK.

  4. 4

    Create or restore your vault

    Install the verified APK, then create or restore your vault.

Verification

Verify Your Downloads

Every release ships with SHA256SUMS.txt + PGP/.sig signatures. Compare digests before installing.

Note: Downloads are served from GitHub Releases.

SHA-256 digests for every installer: View Verification Guide 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
