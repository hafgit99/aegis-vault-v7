产品核心优势

强大、坚韧、绝不妥协

专为高效工作打造的本地架构，在带来极致顺滑体验的同时坚守最高等级的安全边界。

OPFS 沙箱

Local-First: SQLite 与 OPFS 沙箱

数据完全存储在浏览器或 Tauri 原生桌面/Android的私有物理文件系统 (Origin Private File System) SQLite 数据库中，100% 免疫云端故障与网络中断。

Native Messaging

高安全性扩展通信

桌面应用通过动态选择的环回 TCP 端口与扩展程序通信。配对令牌用于验证连接，XChaCha20-Poly1305 用于加密消息帧。

Air-Gap 隔离

物理级 Air-Gap 网络隔离

网络策略会限制意外的出站连接。支持离线使用；启用的功能和配置可能影响网络行为。

多层安全防御体系

安全架构

保险库数据在设备上加密。保护程度取决于主密码强度、保险库保存的 KDF 参数、设备安全性及应用使用方式。没有任何密码学设计能够保证抵御所有攻击场景。

AEAD 认证加密

AES-256-GCM 隔离

每个数据记录均使用通过 WebCrypto HKDF-SHA256 独立派生的 256 位 AES-GCM 密钥进行隔离加密。

硬度密钥推导

Argon2id 密钥推导

Argon2id 会提高离线猜测密码的成本。默认值：Tauri 原生桌面/Android 为 64 MiB / 4 次迭代 / 2 个并行通道；Web/WASM 为 32 MiB / 3 次迭代 / 1 个并行通道。现有保险库沿用已保存的参数。

Zero-Knowledge

零知识安全沙箱

主密码和派生密钥在客户端处理。保护程度也取决于运行应用的设备及用户环境的安全性。

工作原理

从主密码到加密密码库的四步

本页面的任何步骤都不会连接服务器。每一步都在你正在阅读的这台设备上运行。

  1. 1

    由你设置主密码

    它不会以任何形式离开这台设备，也没有重置链接，因为根本没有可重置的账户。

  2. 2

    Argon2id 派生密钥

    密码先由 Argon2id 拉伸成密钥，再由 HKDF-SHA256 拆分为每条记录各自独立的密钥。

  3. 3

    每条记录都用 AES-256-GCM 封装

    磁盘上的密码库文件只保存密文及其认证标签。没有密钥的读取会直接失败，而不是返回错误的结果。

  4. 4

    在本机解锁

    生物识别、安全密钥或 24 词恢复套件都会在这台设备上再次释放密钥，全程不涉及任何网络请求。
