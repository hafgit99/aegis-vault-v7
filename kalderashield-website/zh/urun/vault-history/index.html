功能说明

三种独立方式撤销误操作

删除不等于销毁。移除一个条目会把它移入本地加密回收站，十五天后自动清理；在这段时间内你可以随时恢复或彻底清除。

每个条目都保留自己的密码历史，因此你能看到某个密码过去是什么，并在发现它已在你忘记的某处被轮换时将其回退。

快照是有版本的：应用可以按需创建，也可按你选择的计划自动创建；每个快照在写入前都会加密，并在达到保留上限后清理最旧的。

快照如何创建

捕获密码库

快照记录你密码库当前的状态，或在你按下按钮时触发，或按你配置的计划执行。

先加密

每个快照在写入存储之前都会在设备上加密，因此快照文件本身永远无法读取。

清理旧快照

达到保留上限后，最旧的快照会被删除，因此本地历史不会无限增长。

多层安全防御体系

备份存在哪里，密钥由谁掌握

可选同步为端到端加密

本地快照和导出的备份使用 Argon2id 和 AES-256-GCM 加密，导出备份的密码可以直接使用你的主密码。可选云同步默认关闭；如果你针对自己的云存储或 S3 兼容存储启用它，密码库会在发送前先在设备上加密，因此服务提供方只会收到密文。这项便利取决于你的存储账户保持可访问——密码库文件本身仍然可移植，脱离它也能恢复。

AES-256-GCM

写入前先加密

快照或导出的备份在设备上加密，因此没有你的密码，文件本身毫无用处。

E2EE

你的存储，你的密钥

同步服务只会收到密文。除了你，没有人能解密你存放在那里的内容。

İthalat

导入你已有的数据

Bitwarden、LastPass、1Password、Chrome 的 CSV 和 JSON 导出文件全部在你的设备上处理。

常见问题解答

关于备份与恢复

已删除的记录真的消失了吗？

十五天之内没有。它留在本地加密回收站中，你可以从中恢复，也可以提前彻底清除。

我需要云同步吗？

不需要。快照、加密导出和恢复在单台设备上即可完成，无需账户，也无需网络。

以后我能把密码库迁移到另一个管理器吗？

没有什么阻止你这么做，但请注意导出格式由你选择：如果你希望文件保持受保护，请使用加密备份格式，而不是明文 JSON 转储。
