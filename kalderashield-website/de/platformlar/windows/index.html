KalderaShield unter Windows

Windows 10 und 11 auf x64 werden mit drei Installationsvarianten unterstützt: einem Standard-Setup-Assistenten (NSIS), einem MSI-Paket für verwaltete Verteilung und einer portablen ausführbaren Datei, die ohne Installation läuft.

Für Windows herunterladen Prüfsumme verifizieren
Was Sie erhalten

Drei Wege zur Installation

Der setup.exe-Assistent installiert pro Benutzer oder pro Rechner, legt Startmenü-Verknüpfungen an und bringt einen eigenen Deinstaller mit. Das MSI-Paket gibt es für Umgebungen, in denen die Softwareverteilung dieses Format erwartet. Die portable ausführbare Datei braucht keines davon: entpacken und starten.

Alle drei enthalten dieselbe Anwendung. Tresordatei, verschlüsselte Sicherungen und Einstellungen sind zwischen ihnen portabel, und die SHA-256-Prüfsummen werden für jedes Artefakt veröffentlicht, sodass Sie genau die Datei verifizieren können, die Sie installieren.

Windows-spezifische Schutzmechanismen sind aktiv: Fenster werden mit WDA_EXCLUDEFROMCAPTURE angefordert, was die App aus gewöhnlichen Screenshots, Bildschirmaufnahmen und der Taskwechsel-Vorschau heraushält, und Windows Hello umhüllt die Komfort-Entsperr-Nutzlast mit einem durch TPM 2.0 abgesicherten Plattform-Authenticator.

Erste Schritte unter Windows

Herunterladen und verifizieren

Laden Sie das Installationsprogramm von der Download-Seite und vergleichen Sie seinen SHA-256-Hash mit der passenden Zeile in SHA256SUMS.txt, bevor Sie es ausführen.

Tresor anlegen

Wählen Sie ein Masterpasswort — Argon2id mit 64 MiB, 4 Iterationen und 2 Lanes streckt es zum Tresorschlüssel — und bewahren Sie den 24-Wort-Wiederherstellungsschlüssel nach BIP-39 außerhalb der App auf.

Optional Windows Hello hinzufügen

Richten Sie die Plattform-Entsperrung ein, damit der tägliche Zugriff ein Blick oder eine PIN ist, abgesichert durch TPM 2.0. Das Masterpasswort bleibt stets die eigentliche Wurzel des Tresors.

Sicherheitsarchitektur

Windows-Besonderheiten, die Sie kennen sollten

Signaturen und SmartScreen

Windows-Installationsprogramme tragen noch keine Authenticode-Signatur: Das Projekt besitzt kein Code-Signing-Zertifikat, und sein Release-Gate blockiert unsignierte Artefakte von der Veröffentlichung als offizielle Releases. Solange sich das nicht ändert, kann Windows SmartScreen für Dateien, die Sie aus einem Build beziehen, „Windows hat Ihren PC geschützt“ anzeigen — verifizieren Sie den SHA-256-Hash gegen die veröffentlichten Prüfsummen, und lesen Sie auf der Verifikationsseite nach, was diese Warnung bedeutet und was nicht.

Häufig gestellte Fragen

Fragen zu Windows

Setup.exe, MSI oder portable — was soll ich wählen?

Für einen privaten Rechner den Setup-Assistenten. Für verwaltete Verteilung das MSI-Paket. Für einen USB-Stick oder einen Rechner ohne Installation die portable ausführbare Datei.

Warum warnt SmartScreen vor dem Installationsprogramm?

Weil es unsigniert ist und keine Download-Reputation besitzt. Verifizieren Sie den SHA-256-Hash gegen SHA256SUMS.txt; die Verifikationsseite erklärt den ganzen Zusammenhang, einschließlich warum dies verschwindet, sobald ein Signaturzertifikat vorhanden ist.

Kann ich meinen Tresor auf einen anderen Windows-PC umziehen?

Ja. Exportieren Sie eine verschlüsselte .ks-Sicherung, transportieren Sie sie und spielen Sie sie mit dem Masterpasswort ein. Die Tresordatei ist portabel, nicht an einen Rechner oder eine Installationsvariante gebunden.
