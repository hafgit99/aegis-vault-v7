Installazione Rapida CLI (Comando Singolo)

Scarica e installa l'ultima versione in una sola riga di terminale:

Lo script recupera il numero di versione e le impronte SHA-256 da GitHub Releases mentre è in esecuzione, le confronta con SHA256SUMS.txt e interrompe l’installazione se qualcosa non corrisponde.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
Non ancora pubblicato

I pacchetti Windows e macOS non sono ancora pubblicati, per i motivi indicati sotto.

Windows

Windows 10 a 64 bit e successivi

Installer nativo basato su Tauri (MSI) o eseguibile portatile autonomo.

In arrivo su Microsoft Store

Lo Store rifirma il pacchetto con il proprio certificato: installerai senza avvisi di SmartScreen e senza dover acquistare un certificato di firma del codice.

macOS

In attesa della versione con firma digitale

La certificazione di firma del codice (Code Signing) e la notarizzazione Apple Gatekeeper sono in corso. I pacchetti per macOS sono temporaneamente sospesi.

Segui gli aggiornamenti su GitHub

Per Android

Installazione in 4 passaggi

  1. 1

    Scarica il file APK

    Scegli il pacchetto adatto al tuo dispositivo: APK Universale o ARM64 per la maggior parte dei telefoni.

  2. 2

    Verifica digest e firma

    SHA-256 verifica l'integrità del file; la firma Sigstore autentica il workflow di rilascio.

  3. 3

    Concedi il permesso per origini sconosciute solo durante l'installazione

    Dopo che la verifica è riuscita, concedi questo permesso esclusivamente per l'APK scaricato.

  4. 4

    Crea o ripristina la tua cassaforte

    Installa l'APK verificato, quindi crea o ripristina la tua cassaforte.

Verifica

Verifica i tuoi download

Ogni rilascio include SHA256SUMS.txt e firme PGP/.sig. Confronta i digest prima dell'installazione.

Nota: I download sono distribuiti tramite GitHub Releases.

Digest SHA-256 di tutti i file di installazione: Visualizza guida alla verifica 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
