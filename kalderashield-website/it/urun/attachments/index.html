Prodotto / Allegati

Tieni il file con la credenziale, non in una cartella dei download

I codici di recupero, i documenti d’identità, i certificati e i file di garanzia si allegano al record a cui appartengono e vengono cifrati con quel record, invece di restare in chiaro in una cartella dei download.

Che cosa fa

File trattati come credenziali, non come download

Un allegato appartiene a un record. Elimini il record e il file viene eliminato con esso; ripristini il record e il file torna con esso. Viene memorizzato come viene memorizzato il record, non come file sparso in una cartella del profilo.

Il file viene cifrato sul tuo dispositivo prima di essere scritto. Un singolo record può contenere fino a 250 MB, quindi un documento d’identità scansionato, un insieme di certificati o un video breve rientrano nel database cifrato anziché restare in chiaro sul disco.

Gli allegati seguono il record quando esporti un backup cifrato, quindi un ripristino completo su un altro dispositivo porta con sé anche i file oltre alle credenziali.

Come viene memorizzato un file

Aggiungi il file

Trascini un file nel record, oppure ne scegli uno. Il limite è di 250 MB per file.

Viene cifrato in locale

Il contenuto viene cifrato sul dispositivo usando lo stesso schema del record a cui appartiene.

Va in archivio cifrato

Nell’IndexedDB cifrato viene scritto solo testo cifrato; sul disco non resta nulla di leggibile.

Architettura di Sicurezza

Che cosa non cambiano gli allegati

La cifratura non riduce la superficie d’attacco

Un allegato viene cifrato a riposo come il resto del gestore, quindi un file rubato dal dispositivo non ti consegna i documenti. Non cambia il resto del modello: una password principale debole, un dispositivo compromesso o un gestore che hai già sbloccato espongono comunque ciò che contiene. Gli allegati rendono un record più grande e più prezioso, non più sicuro del record stesso. Tratta un gestore che contiene documenti d’identità come più sensibile di uno che contiene solo password.

250 MB

Per ogni singolo file

Abbastanza per un documento scansionato, un insieme di certificati o un breve video clip senza uscire dall’archivio cifrato.

IndexedDB

Cifrato a riposo

I file finiscono in un IndexedDB cifrato anziché nel file system in chiaro.

Dışa aktarım

Viaggia con il record

Gli allegati sono inclusi in un backup cifrato e ripristinati insieme alla credenziale.

Domande Frequenti

Informazioni sugli allegati

Quali tipi di file sono ammessi?

L’editor accetta i tipi comuni di documento, immagine, video e archivio e cifra qualsiasi cosa accetti. Un singolo file è limitato a 250 MB.

Posso aprire un allegato da un altro dispositivo?

Sì, dopo aver ripristinato il backup cifrato. Il file viaggia con il record anziché come download separato.

Che cosa succede agli allegati quando elimino un record?

Segnano il record nel cestino cifrato per la stessa finestra di 15 giorni e vengono rimossi con esso se lo elimini definitivamente.
