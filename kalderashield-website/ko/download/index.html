CLI 단일 명령어 빠른 설치

터미널에서 한 줄 명령어로 최신 버전을 설치하세요:

스크립트는 실행 중에 GitHub Releases에서 버전 번호와 SHA-256 체크섬을 받아 SHA256SUMS.txt와 비교하며, 하나라도 맞지 않으면 설치를 중단합니다.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
아직 공개되지 않음

Windows 및 macOS 패키지는 아래에 설명된 이유로 아직 공개되지 않았습니다.

Windows

Windows 10 64비트 이상

Tauri 기반 최적화 네이티브 Windows MSI 설치 프로그램 또는 포터블 EXE.

Microsoft Store 출시 예정

Store는 자신 인증번로 패키지를 다시 서명합니다. SmartScreen 경고 없이 설치하거나 코드 서명 인증서를 구매할 필은 없습니다.

macOS

공식 코드 서명 빌드 준비 중

Apple Gatekeeper 및 코드 서명(Code Signing) 공증 절차가 진행 중입니다. 공식 서명 빌드가 준비될 때까지 macOS 설치 프로그램 제공이 일시 중단됩니다.

GitHub에서 릴리스 소식 확인

Android 사용자용

4단계 간편 설치

  1. 1

    APK 파일 다운로드

    기기에 맞는 패키지를 선택하세요: 대부분의 스마트폰에는 유니버설 또는 ARM64 APK가 적합합니다.

  2. 2

    다이제스트 및 서명 검증

    SHA-256으로 파일 무결성을 검증하고, Sigstore 서명으로 릴리스 워크플로를 인증합니다.

  3. 3

    설치 중에만 알 수 없는 출처 권한을 부여하세요

    검증이 성공한 후 다운로드한 APK에 대해서만 이 권한을 허용하세요.

  4. 4

    보관함 생성 또는 복원

    검증된 APK를 설치하고 보관함을 새로 생성하거나 복원하세요.

검증

다운로드 무결성 검증

모든 릴리스는 SHA256SUMS.txt 및 PGP/.sig 서명과 함께 배포됩니다. 설치 전 해시를 확인하세요.

참고: 다운로드는 GitHub Releases를 통해 제공됩니다.

모든 설치 파일의 SHA-256 다이제스트: 검증 가이드 보기 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
