機能 / 履歴と復元

誤りは、自分で選ぶ時期に元に戻せる

削除したレコードは 15 日間復元できます。各項目は個別のパスワード履歴を持ちます。暗号化されたスナップショットで、誰にも頼らず過去に戻れます。

KalderaShield をダウンロード ソースを見る
できること

誤りを 3 つの方法で取り消す

削除は破壊ではありません。項目を外すと暗号化されたローカルゴミ箱に入り、15 日後に自動で消去されます。この期間内ならいつでも復元も、完全削除もできます。

各項目は個別のパスワード履歴を保ちます。以前のパスワードを確認できます。忘れていた場所で変更されていた場合に、巻き戻せます。

スナップショットには版があります。ボタンで、または自分で選んだスケジュールで自動取得できます。書き込む前に暗号化し、保持数の上限に達したら古いものから削除します。

スナップショットの取り方

保管庫の状態を記録する

ボタンを押したとき、または設定したスケジュールで、保管庫の現在の状態をスナップショットに記録します。

先に暗号化する

各スナップショットは保存前に端末内で暗号化されます。スナップショットファイル単体では読めません。

古いものから削除する

保持数の上限に達すると、古いスナップショットから削除されます。ローカルの履歴が無制限に増えることはありません。

セキュリティアーキテクチャ

バックアップの保存先と鍵の持ち主

任意の同期はエンドツーエンド暗号化

ローカルのスナップショットと書き出したバックアップは、Argon2id と AES-256-GCM で暗号化されます。書き出しバックアップのパスワードには、マスターパスワードを使えます。任意のクラウド同期は初期状態で無効です。自分で用意したストレージや S3 ストレージに対して有効にした場合、保管庫は送信前に端末上で暗号化されます。提供者が受け取るのは暗号文だけです。この便利さは、ストレージのアカウントに到達できることに依存します。保管庫ファイル自体は移植可能で、それなしでも復元できます。

AES-256-GCM

書き込み前に暗号化

スナップショットも書き出したバックアップも、端末上で暗号化されます。パスワードがなければ、ファイル単体では使えません。

E2EE

ストレージも鍵も自分持ち

同期先が受け取るのは暗号文だけです。保存した内容を復号できるのは、あなただけです。

İthalat

手持ちデータを取り込める

Bitwarden、LastPass、1Password、Chrome の CSV と JSON の書き出しデータは、すべて端末内で処理されます。

よくある質問

バックアップと復元について

削除したレコードは本当に消えたのですか。

15 日間は消えません。暗号化されたローカルゴミ箱に入り、そこから復元するか、早めに完全削除できます。

クラウド同期は必要ですか。

不要です。スナップショット、暗号化した書き出し、復元は、いずれもアカウントもネットワークも無い 1 台の端末で動作します。

後から別の管理ツールへ移せますか。

妨げるものはありません。ただし書き出し方法はあなたが選びます。ファイルを保護したい場合は、平文の JSON ではなく、暗号化バックアップ形式を使ってください。
