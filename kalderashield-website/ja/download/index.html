CLI コマンドで一発インストール

ターミナルから1行のコマンドで最新版をインストール:

スクリプトは実行時に GitHub Releases からバージョン番号と SHA-256 チェックサムを取得し、SHA256SUMS.txt と照合します。一致しない場合はインストールを中止します。

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
未公開

Windows と macOS のパッケージは、下Reasons に記載した理由によりまだ公開されていません。

Windows

Windows 10 64ビット以降

Tauri 最適化ネイティブ Windows MSI インストーラーまたはポータブル版 EXE。

Microsoft Store で公開予定

Store がパッケージを独自の誌明書で再署名します。SmartScreen の警告なしでインストールでき、コード署名証明書を購入する必要はありません。

macOS

公式コード署名版の準備中

Apple Gatekeeper およびコード署名（Code Signing）の公証手続きを進めております。署名済み正式ビルドの準備が整うまで、macOS版インストーラーの配布を一時停止しております。

Android向け

4つのステップでインストール

  1. 1

    APKファイルをダウンロード

    お使いの端末に適したパッケージを選択します（ほとんどのスマートフォンにはユニバーサルまたはARM64が最適です）。

  2. 2

    ダイジェストと署名を検証

    SHA-256でファイル整合性を検証し、Sigstore署名でリリースワークフローを認証します。

  3. 3

    インストール時のみ「不明な提供元」の権限を付与

    検証に成功した後、ダウンロードしたAPKに対してのみこの権限を許可してください。

  4. 4

    ボルトを作成または復元

    検証済みのAPKをインストールし、ボルトを新規作成または復元します。

検証

ダウンロードの検証

すべてのリリースには SHA256SUMS.txt と PGP/.sig 署名が付属します。インストール前にダイジェストを比較してください。

注意： ダウンロードは GitHub Releases で提供されます。

すべてのインストーラーのSHA-256ダイジェスト： 検証ガイドを見る 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
