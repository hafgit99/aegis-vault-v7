تثبيت سريع عبر سطر الأوامر CLI (أمر واحد)

قم بتنزيل أحدث إصدار وتثبيته بأمر واحد في الطرفية:

يجلب السكربت رقم الإصدار وبصمات SHA-256 من GitHub Releases أثناء تشغيله، ويقارنها بـ SHA256SUMS.txt، ويوقف التثبيت إذا لم يتطابق أي منها.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
لم يُنشر بعد

حزمتي Windows و macOS لم تُنشر بعد، للأسباب الموضحة أدناه.

Windows

Windows 10 بإصدار 64 بت فما فوق

مثبت MSI أصلي ومحسن مبني على Tauri أو نسخة محمولة EXE.

قريبًا على متجر Microsoft

يعيد المتجر توقيع الحزمة بشهادته الخاصة فتت التثبيت دون تحذير SmartScreen ودون حاجة إلى شراء شهادة توقيع الشيفرة.

macOS

بانتظار النسخة الموقعة رسمياً

عملية توثيق وتوقيع الكود البرمجي (Code Signing) وApple Gatekeeper قيد الإجراء حالياً. تم تعليق حزم تثبيت macOS مؤقتاً حتى توفر النسخة الموقعة رسمياً.

متابعة الإصدارات على GitHub

لنظام Android

التثبيت في 4 خطوات

  1. 1

    تنزيل ملف APK

    اختر الحزمة المناسبة لهاتفك: الحزمة الشاملة Universal أو ARM64 لمعظم الهواتف الحديثة.

  2. 2

    تحقق من الخلاصة والتوقيع

    يتحقق SHA-256 من سلامة الملف؛ بينما يوثّق توقيع Sigstore مسار عمل الإصدار.

  3. 3

    امنح إذن المصادر غير المعروفة فقط أثناء التثبيت

    بعد نجاح التحقق، امنح هذا الإذن حصرياً لحزمة APK التي تم تنزيلها.

  4. 4

    أنشئ خزينتك أو استعدها

    ثبّت حزمة APK التي تم التحقق منها، ثم أنشئ خزينتك أو استعدها.

التحقق

التحقق من التنزيلات

يصدر كل إصدار مع ملف SHA256SUMS.txt وتواقيع PGP/.sig الرقمية. قارن البصمات قبل بدء التثبيت.

ملاحظة: تُقدَّم التنزيلات عبر GitHub Releases.

ملخصات SHA-256 لجميع ملفات التثبيت: عرض دليل التحقق 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
