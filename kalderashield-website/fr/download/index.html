Installation Rapide CLI (Commande Unique)

Téléchargez et installez la dernière version en une seule ligne :

Pendant son exécution, le script récupère le numéro de version et les empreintes SHA-256 depuis GitHub Releases, les compare à SHA256SUMS.txt et interrompt l'installation si quoi que ce soit ne correspond pas.

curl -fsSL https://{{DOMAIN}}/install.sh -o install.sh
less install.sh          # once okuyun
sh install.sh
Pas encore publié

Les paquets Windows et macOS ne sont pas encore publiés, pour les raisons indiquées ci-dessous.

Windows

Windows 10 64 bits et supérieur

Installateur MSI natif optimisé basé sur Tauri ou exécutable portable autonome.

Bientôt disponible sur le Microsoft Store

Le Store resigne le paquet avec son propre certificat : vous installez sans avertissement SmartScreen, sans avoir à acheter de certificat de signature de code.

macOS

En attente de version signée officielle

Le processus de signature de code (Code Signing) et de notarisation Apple Gatekeeper est en cours. Les packages macOS sont temporairement suspendus jusqu'à la version signée.

Suivre les versions sur GitHub

Pour Android

Installation en 4 étapes

  1. 1

    Téléchargez le fichier APK

    Choisissez le paquet adapté à votre appareil : APK Universel ou ARM64 pour la plupart des téléphones.

  2. 2

    Vérifiez l'empreinte et la signature

    Le SHA-256 garantit l'intégrité du fichier ; la signature Sigstore authentifie le workflow de publication.

  3. 3

    N'accordez l'autorisation de sources inconnues que lors de l'installation

    Une fois la vérification réussie, n'accordez cette autorisation que pour l'APK téléchargé.

  4. 4

    Créez ou restaurez votre coffre-fort

    Installez l'APK vérifié, puis créez ou restaurez votre coffre-fort.

Vérification

Vérifiez vos téléchargements

Chaque version est publiée avec SHA256SUMS.txt et des signatures PGP/.sig. Comparez les empreintes avant l'installation.

Remarque : Les téléchargements sont distribués via GitHub Releases.

Empreintes SHA-256 de tous les fichiers d'installation : Consulter le guide de vérification 

# indirdiğiniz dosyanın özetini karşılaştırın
sha256sum -c SHA256SUMS.txt

# ya da tek dosya için
sha256sum KalderaShield-latest-linux-x64.AppImage
