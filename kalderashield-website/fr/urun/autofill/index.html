Produit / Remplissage automatique

Un clic, et uniquement sur le site visé

L’extension associe les sites par domaine enregistrable, et non par la chaîne d’URL, de sorte qu’un hébergeur mutualisé n’obtienne jamais le mauvais identifiant. La liste déroulante s’affiche dans un Shadow DOM fermé, hors de portée de la page.

Ce qu’il fait

Une association qu’un faux clone d’hôte ne peut pas tromper

Une URL est ramenée à son domaine enregistrable à l’aide de la liste Public Suffix List complète de Mozilla, intégrée à l’extension sous forme d’instantané figé par empreinte. Les noms d’hôte ne sont jamais comparés comme chaînes brutes : un sous-domaine ne peut donc pas emprunter un identifiant appartenant à un autre site.

La liste déroulante, le générateur de mots de passe et l’avertissement d’hameçonnage s’affichent tous dans un Shadow DOM fermé attaché à la page. Le JavaScript de la page ne peut ni les lire, ni les réécrire, ni les recouvrir pour capturer ce que vous saisissez.

L’extension communique avec l’application de bureau par un port Loopback dynamique, et les trames de message sont chiffrées. La copie d’un mot de passe le place dans le presse-papiers pour une durée limitée : il n’y reste pas indéfiniment.

Comment se fait l’association

Vous activez un champ

Le script de contenu repère un champ de connexion et demande à l’application les identifiants correspondant à ce site.

Le domaine est ramené à l’essentiel

Votre URL est normalisée en eTLD+1 à l’aide de la liste Public Suffix List intégrée, puis comparée aux domaines enregistrés dans le coffre.

Vous choisissez, et le remplissage se fait

La liste déroulante n’affiche que les enregistrements de ce domaine, et celui que vous choisissez est saisi dans le champ.

Architecture de Sécurité

Ce que le remplissage automatique ne vous protège pas

Le remplissage automatique est un confort, pas un contrôle

Le remplissage automatique complète un formulaire ; il ne détermine pas si le site est honnête. L’extension recherche les indices d’hameçonnage évidents en comparant le domaine à ce que votre coffre connaît déjà, mais un site qui imite un domaine que vous n’avez jamais enregistré paraîtra nouveau plutôt que familier. Un gestionnaire de mots de passe réduit les erreurs de saisie et la réutilisation. Il ne remplace pas l’authentification à deux facteurs, et il ne peut plus rien une fois les identifiants déjà saisis dans une page hostile depuis le début.

eTLD+1

Association par domaine enregistrable

Fondée sur la liste Public Suffix List complète de Mozilla, figée en instantané par empreinte, de sorte que l’hébergement mutualisé est correctement traité.

Shadow DOM

Fermé et isolé

La liste déroulante, le générateur et l’avertissement d’hameçonnage s’affichent là où le script de la page ne peut ni les voir ni les modifier.

İzinler

Portée volontairement limitée

Les scripts de contenu ne traitent que http et https : les schémas internes du navigateur restent hors de portée.

Foire Aux Questions

À propos de l’extension

L’extension a-t-elle besoin d’une connexion Internet ?

Non. Tout ce dont elle a besoin se trouve sur votre appareil : le coffre est local, et la connexion à l’application de bureau passe par un port Loopback sur votre propre machine.

Que se passe-t-il si l’application de bureau est fermée ?

La fenêtre indique que le coffre est verrouillé et la liste déroulante n’affiche aucun enregistrement. Rien n’est mis en cache dans le navigateur : une application fermée signifie pas de remplissage automatique.

Quels navigateurs sont pris en charge ?

Chrome, Edge et Firefox, avec Manifest V3. Une version pour Safari existe et nécessite un enveloppeur local pour fonctionner.
