Plateformes / Windows

KalderaShield sous Windows

Windows 10 et 11 sur x64 sont pris en charge avec trois formes d’installation : un assistant d’installation NSIS standard, un package MSI pour le déploiement géré et un exécutable portable qui fonctionne sans installation.

Télécharger pour Windows Vérifier la somme de contrôle
Ce que vous obtenez

Trois façons d’installer

L’assistant setup.exe installe par utilisateur ou par machine, ajoute des raccourcis au menu Démarrer ainsi que son propre désinstalleur. Le package MSI existe pour les environnements où le déploiement logiciel attend ce format. L’exécutable portable n’a besoin d’aucun de ces éléments : décompressez et exécutez.

Les trois contiennent la même application. Le fichier du coffre, les sauvegardes chiffrées et les paramètres sont portables de l’un à l’autre, et les sommes de contrôle SHA-256 sont publiées pour chaque artefact afin que vous puissiez vérifier le fichier exact que vous installez.

Les protections propres à Windows sont actives : les fenêtres sont demandées avec WDA_EXCLUDEFROMCAPTURE, ce qui tient l’application hors des captures d’écran ordinaires, des enregistrements d’écran et de l’aperçu du sélecteur de tâches, et Windows Hello enveloppe la charge utile de déverrouillage de confort avec un authentificateur de plateforme adossé à un TPM 2.0.

Démarrer sous Windows

Télécharger et vérifier

Récupérez l’installateur depuis la page de téléchargement, puis comparez son hachage SHA-256 à la ligne correspondante dans SHA256SUMS.txt avant de l’exécuter.

Créer le coffre

Choisissez un mot de passe principal — Argon2id avec 64 MiB, 4 itérations et 2 voies l’étire en clé du coffre — et conservez la clé de récupération BIP-39 de 24 mots hors de l’application.

Ajouter Windows Hello, au choix

Inscrivez le déverrouillage de plateforme pour que l’accès quotidien soit un regard ou un code PIN, adossé au TPM 2.0. Le mot de passe principal demeure toujours la vraie racine du coffre.

Architecture de Sécurité

Ce qu’il faut savoir côté Windows

Signatures et SmartScreen

Les installateurs Windows ne portent pas encore de signature Authenticode : le projet n’a pas de certificat de signature de code, et son garde-fou de version empêche la publication d’artefacts non signés comme versions officielles. Tant que cela ne change pas, Windows SmartScreen peut afficher « Windows a protégé votre PC » pour des fichiers obtenus par une compilation — vérifiez le hachage SHA-256 contre les sommes de contrôle publiées, et voyez la page de vérification pour ce que cet avertissement signifie et ne signifie pas.

Architecture x64

Un seul téléchargement sert aux deux. L’application est livrée comme application de bureau Tauri avec une interface en WebView.

TPM 2.0

Déverrouillage Windows Hello

L’authentificateur de plateforme WebAuthn PRF enveloppe la charge utile de déverrouillage ; le matériel de clé d’enveloppement ne quitte jamais le matériel sécurisé.

WDA_EXCLUDEFROMCAPTURE

Exclusion de capture

Les fenêtres de l’application sont exclues de la capture d’écran ordinaire. Un logiciel de capture privilégié est hors du modèle de menace, comme partout.

Foire Aux Questions

Questions Windows

Setup.exe, MSI ou portable — que choisir ?

Pour une machine personnelle, l’assistant d’installation. Pour un déploiement géré, le MSI. Pour une clé USB ou une machine où vous préférez ne rien installer, l’exécutable portable.

Pourquoi SmartScreen met-il en garde contre l’installateur ?

Parce qu’il est non signé et sans réputation de téléchargement. Vérifiez le hachage SHA-256 contre SHA256SUMS.txt ; la page de vérification explique le tableau complet, y compris la raison pour laquelle cela disparaît une fois un certificat de signature en place.

Puis-je déplacer mon coffre vers un autre PC Windows ?

Oui. Exportez une sauvegarde chiffrée .ks, déplacez-la et restaurez-la avec le mot de passe principal. Le fichier du coffre est portable, lié ni à une machine ni à une forme d’installation.
